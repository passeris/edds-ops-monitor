# Stuttgart Airport Live Operations Monitor

## Introduction

The Operations monitor for Stuttgart Airport (EDDS) is a dashboard designed to give you up-to-date information on current flight operations at Stuttgart Flughafen in Stuttgart, Germany. The following capabilities that are to be demonstrated by this project are the following:

- Design and build a REST API in Python (FastAPI) with clean endpoint contracts
- Model relational data and write analytical SQL (PostgreSQL) — schemas, joins, deduplication
- Cache and integrate third-party APIs with cost/quota awareness and graceful failure handling
- Deploy and run serverless workloads on AWS (Lambda, EventBridge, IAM, S3/DynamoDB)
- Containerize applications with Docker and run them on managed cloud infrastructure
- Provision reproducible infrastructure as code (Terraform or CDK)
- Set up CI/CD pipelines with automated testing and rollback
- Serve a web frontend that talks to a deployed API (auth, CORS, HTTPS, domains)
- Implement observability: logging, monitoring, alerting, cost tracking
- Operate securely: secret management, least-privilege access, backup and recovery
